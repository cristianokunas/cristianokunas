## 👋 Hello, I'm Cristiano Künas

🎓 I'm a PhD candidate in Computer Science (HPC) at **UFRGS**, passionate about High-Performance Computing (HPC), scientific software, and reproducible research.

I work where scientific applications meet the machines they run on: GPU compression,
parallel performance, and the operational side of keeping an HPC cluster alive.

🔬 **Research** — lossless and lossy compression for 3D floating-point fields produced by
stencil-based scientific simulation, ported and tuned across AMD (CDNA2/CDNA3/RDNA3) and
NVIDIA GPUs.

🏭 **Industry** — build automation and performance validation for production scientific
computing codes: multi-compiler build, OpenMP/MPI configurations, automated regression 
and benchmark suites with result tracking.

🖥️ **Operations** — volunteer HPC administrator at UFRGS's
[LPPD](https://pcad.inf.ufrgs.br) since Jan 2022: Slurm across more than 40 nodes and GPUs
serving researchers — accounting, QoS, fairshare, node provisioning, storage, monitoring, hardware maintenance.
